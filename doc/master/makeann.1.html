Name

makeann — prepare audio prompts for playback by rtpproxy

Synopsis

makeann [-l limit [-L]] infile [outfile_template]

DESCRIPTION

makeann encodes an audio prompt into every codec that rtpproxy(8) can play it out in, using the P (play) command.

infile has to contain raw signed 16-bit little-endian mono samples at 8 kHz, with no header. Such a file can be produced, for example, with sox:

sox prompt.wav -t raw -r 8000 -c 1 -b 16 -e signed-integer \
    -L prompt.sln

For each codec, the encoded prompt is written into a file named outfile_template.pt, where pt is the RTP payload type of the codec. If outfile_template is not given, infile is used instead. The following files are produced:

outfile_template.0

G.711 u-law.

outfile_template.3

GSM 06.10, if GSM support has been compiled in.

outfile_template.8

G.711 A-law.

outfile_template.9

G.722 at 64 kbit/s, if G.722 support has been compiled in.

outfile_template.18

G.729, if G.729 support has been compiled in.

To play the prompt, give outfile_template as the prompt name to the rtpproxy P command. rtpproxy tries the payload types listed in the command (or those of the session, if session is given instead) in order and plays the first one for which the file exists. Since rtpproxy changes its working directory to / when it daemonizes (unless started with -D), the prompt name should normally be an absolute path.

OPTIONS

-l limit

Encode at most limit samples (8000 samples per second) of the input.

-L

Loop mode: repeat the input as many times as needed to produce exactly limit samples of output. Requires -l.

EXIT STATUS

makeann exits 0 on success, and 1 if an error occurs.

EXAMPLES

Prepare ringback.sln for playback as ringback, producing ringback.0, ringback.8 and so on:

makeann ringback.sln ringback

Make a 30 seconds long prompt out of a shorter one:

makeann -l 240000 -L beep.sln beep30
