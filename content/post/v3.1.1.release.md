This is a minor bug fix release, fixing several issues and making some incremental improvements.

See the [GitHub release](https://github.com/sippy/rtpproxy/releases/tag/v3.1.1) for downloads, and the [full changelog](https://github.com/sippy/rtpproxy/compare/v3.1.0...v3.1.1).

## Bug Fixes

- Fixed the `N` (new port) modifier to select the correct IP address in the presence of the direction configuration;
- Fixed some potential non-initialized accesses in the extended stat command code (reported by OSS-Fuzz);
- Reply buffer overflow in the subcommand stat processing path is now handled gracefully.

## Non-code Changes

- Ubuntu 20.04 has been replaced with 24.04 in GitHub Actions;
- The build glue has been re-generated with automake 1.17 and autoconf 2.72;
- A "Release" CI job has been added to package the source files and attach them to the release automatically, as requested by the FreeBSD packagers.
