## Notable Changes

### HEP integration module

The new `acct_rtcp_hep` loadable module allows reporting RTCP packets to a HEP (Homer) server.

### RFC 2833 capture module

The new `catch_dtmf` module has been added in collaboration with the OpenSIPS project. The module allows the RTPProxy to notify a call controller (i.e. a SIP proxy or B2BUA), when so instructed, of any DTMF-style events present in the real-time stream. The notification can be enabled on a per-stream basis, and is done via the same mechanism as the "no-audio timeout" notifications to simplify integration.

### Support for Link-Time Optimization (LTO)

Optional support for LTO has been added into the build system, allowing to utilize the latest enhancements in compiler technology (`--enable-lto` when running the configure script).

### Numerous performance improvements

A number of performance-critical components have been refactored.

### Automatic test coverage report integration

Coveralls.io has been integrated to provide test coverage tracking for all actively developed branches.

### Test coverage improvements

Test coverage has been vastly improved, from 52% to 91%.
